人狼メモ プライバシーポリシー

最終更新日：2026年8月10日

「人狼メモ」（以下「本アプリ」）は、利用者のプライバシーを尊重し、 利用者に関する情報を以下の方針に基づいて取り扱います。

1. 本アプリに入力する対局データ

本アプリでは、人狼ゲームの記録および推理支援のため、 利用者が以下のような情報を入力できます。

  • 参加者に関する情報
  • 投票記録
  • 占い結果
  • 霊能結果
  • 配役情報
  • 参加者に関するメモ
  • その他、対局に関する情報

これらの情報は、利用者の端末内にのみ保存されます。

本アプリの開発者が管理するサーバーへの送信、 他の利用者との共有、広告事業者その他の第三者への提供は行いません。

また、本アプリによる役職候補の分析、盤面の整合性判定その他の推理処理についても、 利用者の端末内で行われます。

2. Firebase の利用

本アプリでは、アプリの利用状況の把握、品質改善、 およびアップデートに関する設定情報の取得のため、 Google LLC が提供する Firebase の以下のサービスを利用しています。

  • Google Analytics for Firebase
  • Firebase Remote Config

これらのサービスの利用に伴い、アプリの利用状況、 端末やOSに関する情報、アプリのバージョン、 言語・地域に関する情報、 アプリまたは端末を識別するための技術的な識別情報などが、 Google に送信される場合があります。

これらの情報は、本アプリの利用状況の分析、品質改善、 設定情報の取得、および必要なアップデートの案内などのために利用します。

本アプリに入力された参加者名、投票記録、占い結果、霊能結果、 配役情報、メモなどの対局データを、 Firebase Analytics または Firebase Remote Config を通じて送信することはありません。

3. アクセス解析

本アプリでは、利用状況の把握および品質改善のため、 Google Analytics for Firebase を利用しています。

Google Analytics for Firebase により、 アプリの起動や利用状況、端末・OS・アプリに関する技術情報などが 自動的に収集される場合があります。

現時点では、利用者が入力した対局内容を含む独自の分析イベントは送信していません。

今後、アプリの品質改善のために新たな分析情報を収集する場合は、 必要に応じて本プライバシーポリシーおよび ストア上のプライバシー情報を更新します。

4. Firebase Remote Config

本アプリでは、最低利用可能バージョンなどのアプリ設定を取得するため、 Firebase Remote Config を利用しています。

Firebase Remote Config は、利用者の端末に適切な設定情報を提供するため、 アプリや端末に関する技術情報を取り扱う場合があります。

本アプリでは、Firebase Remote Config を主に、 古いバージョンのアプリに対してアップデートを案内する目的で利用しています。

5. 広告およびトラッキング

本アプリでは、第三者広告を表示していません。

また、広告配信を目的として利用者を追跡したり、 本アプリで得られた情報を他社のアプリやWebサイトで収集された情報と組み合わせて、 広告目的で利用したりすることはありません。

6. 第三者への情報提供

本アプリに入力された対局データを、 開発者が第三者へ販売または提供することはありません。

ただし、本アプリで利用している Firebase のサービス提供に必要な範囲で、 技術情報や利用状況に関する情報が Google LLC に送信される場合があります。

Firebase および Google における情報の取り扱いについては、 Google が公開するプライバシーポリシーおよび Firebase に関するプライバシー情報をご確認ください。

7. データの保存および削除

本アプリに入力された対局データは、利用者の端末内に保存されます。

利用者は、本アプリ内の削除機能を使用することで、 保存された対局データを削除できます。

また、本アプリを端末からアンインストールすることによって、 本アプリが端末内に保存したデータを削除できます。

Firebase を通じて Google が取り扱う情報については、 Google の定める方針に従って管理されます。

8. 未成年者の利用

本アプリは、人狼ゲームの対局記録および推理支援を目的としたアプリです。

本アプリでは、年齢、氏名、住所などの個人情報の登録を求める機能は提供していません。

9. 本プライバシーポリシーの変更

本アプリの機能追加、利用する外部サービスの変更、 法令その他の事情により、 本プライバシーポリシーを変更することがあります。

重要な変更がある場合は、 本ページその他の適切な方法でお知らせします。
